TICKET TITLE:
Access Denied When Opening Shared Folder

CATEGORY:
File Access / Permissions

PRIORITY:
Medium

ENVIRONMENT:
Operating System: Windows 10
Device Type: Desktop PC
Folder Location: Network shared drive
Location: Office Environment
Account Type: Domain user account


--------------------------------

USER ISSUE:
User reports receiving an “Access Denied” message when attempting to open a shared network folder required for their daily work.

---------------------------------

INITIAL CHECKS:
- Confirmed the correct folder path was being accessed.
- Verified the user was logged into the correct domain account.
- Asked whether the user had previously been able to access the folder.
- Confirmed the issue was affecting only this user.

--------------------------------

TROUBLESHOOTING STEPS:
1. Checked the user’s group memberships.
2. Verified folder permissions on the shared drive.
3. Confirmed the user did not have the required access rights.
4. Added the user to the appropriate security group following company policy.
5. Asked the user to log out and log back in to refresh permissions.
6. Confirmed the user could successfully access the folder.

--------------------------------

RESOLUTION:
The issue was resolved after updating the user’s group membership and refreshing permissions.

--------------------------------

OUTCOME:
User confirmed successful access to the shared folder and was able to resume work.
--------------------------------

TICKET STATUS:
Resolved
