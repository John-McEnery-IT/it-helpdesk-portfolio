TICKET TITLE:
Computer Running Slowly Due to Low Disk Space

CATEGORY:
Operating System / Performance

PRIORITY:
Medium

ENVIRONMENT:
Operating System: Windows 10
Device Type: Desktop PC
Folder Location: Network shared drive
Location: Office Environment
Account Type: Domain user account


--------------------------------

USER ISSUE:
User reports that their computer is running slowly and applications take a long time to open.

---------------------------------

INITIAL CHECKS:
- Confirmed the user was experiencing slow system performance.
- Asked when the performance issue began.
- Verified no recent hardware changes were made.
- Confirmed the issue was affecting only this device.

--------------------------------

TROUBLESHOOTING STEPS:
1. Checked available disk space on the system drive.
2. Identified the system drive was critically low on free space.
3. Ran Disk Cleanup to remove temporary files.
4. Deleted unnecessary files from the Downloads and Recycle Bin.
5. Uninstalled unused applications following company policy.
6. Restarted the computer to apply changes.

--------------------------------

RESOLUTION:
The issue was resolved after freeing up disk space on the system drive, which improved overall system performance.

--------------------------------

OUTCOME:
User confirmed the system performance returned to normal and applications were opening as expected.
--------------------------------

TICKET STATUS:
Resolved
