# Qwiklabs – File System Basics (Windows & Linux)

## Lab Overview
This lab focused on basic file system operations in both Windows and Linux environments. The objective was to create and manage folders using native tools in each operating system.

## Tasks Performed
- Created folders using File Explorer in Windows
- Created folders using command-line tools in Linux
- Verified successful folder creation in both environments

## Operating Systems Used
- Windows
- Linux

## Tools Used
- Windows File Explorer
- Linux terminal

## What This Demonstrates
This lab demonstrates familiarity with basic file system concepts across multiple operating systems, including directory structure awareness and the ability to perform simple administrative tasks using both graphical and command-line tools.

## Relevance to IT Support
Creating and managing folders is a fundamental IT support task. These skills are directly applicable when troubleshooting permissions issues, organizing shared resources, and assisting users with file management across different operating systems.
