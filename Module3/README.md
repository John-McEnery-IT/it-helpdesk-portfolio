# Module 3 – Operating Systems, Users, and Hardware

## Module 3 Summary
Module 3 focused on core operating system concepts and common support tasks handled by Tier 1 IT support technicians. Topics included user authentication, file and folder permissions, system performance issues, and hardware troubleshooting.

During this module, I documented realistic helpdesk tickets covering scenarios such as users being unable to log in to Windows, access being denied to shared folders, slow system performance caused by low disk space, and network printer issues. Each ticket demonstrates a structured troubleshooting approach, appropriate use of built-in Windows tools and services, and clear communication with users.

These examples reflect everyday support tasks in a professional IT environment and highlight my ability to diagnose operating system issues, manage user access, resolve performance problems, and handle common hardware-related incidents while following established support procedures.

## Tickets Included
- User unable to log in to Windows
- Access denied when opening a shared folder
- Computer running slowly due to low disk space
- Printer not responding
