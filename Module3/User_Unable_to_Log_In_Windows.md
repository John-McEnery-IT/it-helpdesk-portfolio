TICKET TITLE:
User Unable to Log In to Windows

CATEGORY:
User Account / Authentication

PRIORITY:
Medium

ENVIRONMENT:
Operating System: Windows 10
Device Type: Desktop PC
Network Type: Wired and Wireless
Location: Office Environment
Account Type: Domain user account


--------------------------------

USER ISSUE:
User reports being unable to log in to their Windows account. The system displays an incorrect password error after multiple attempts.

---------------------------------

INITIAL CHECKS:
- Confirmed the user was entering the correct username.
- Verified whether Caps Lock or Num Lock was enabled.
- Asked if the user had recently changed their password.
- Confirmed whether the issue was affecting only this user.

--------------------------------

TROUBLESHOOTING STEPS:
1. Verified the user account was not locked out.
2. Confirmed the user was connected to the corporate network.
3. Attempted to log in using a known working keyboard.
4. Reset the user’s password following company policy.
5. Asked the user to log in using the new temporary password.
6. Confirmed successful login and access to the desktop.

--------------------------------

RESOLUTION:
The issue was resolved after resetting the user’s password. The user was able to log in successfully using the new credentials.

--------------------------------

OUTCOME:
User confirmed successful access to their Windows account and normal system functionality.
--------------------------------

TICKET STATUS:
Resolved
