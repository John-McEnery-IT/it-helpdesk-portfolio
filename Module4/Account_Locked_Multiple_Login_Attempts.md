TICKET TITLE:
Account Locked After Multiple Failed Login Attempts

CATEGORY:
Security / User Account 

PRIORITY:
Medium

ENVIRONMENT:
Device: Desktop PC
Operating System: Windows 10
Account Type: Domain user account
Location: Office Environment


--------------------------------

USER ISSUE:
User reports being unable to log in to their account after multiple failed login attempts. The account appears to be locked due to security policy.

---------------------------------

INITIAL CHECKS:
- Verified the user’s identity according to company policy.
- Confirmed the account lockout message was displayed.
- Asked whether the user had recently changed their password.
- Confirmed the issue was affecting only this user.

--------------------------------

TROUBLESHOOTING STEPS:
1. Verified the account was locked in the directory service.
2. Reviewed recent failed login attempts.
3. Confirmed the lockout was triggered by incorrect password entries.
4. Unlocked the user account following security procedures.
5. Reset the user’s password in accordance with company policy.
6. Asked the user to log in and confirm successful access.

--------------------------------

RESOLUTION:
The issue was resolved by unlocking the account and resetting the user’s password.


--------------------------------

OUTCOME:
User confirmed successful access to their account and normal system functionality.
--------------------------------

TICKET STATUS:
Resolved
