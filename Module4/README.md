# Module 4 – Security and System Administration

## Module 4 Summary
Module 4 focused on core security principles and system administration practices commonly handled by Tier 1 IT support technicians. Topics included user account security, least-privilege access, threat awareness, and appropriate incident response procedures.

During this module, I documented realistic helpdesk tickets involving suspected phishing emails, account lockouts due to failed login attempts, software installation requests requiring administrative approval, and antivirus threat detections. Each ticket demonstrates an emphasis on risk reduction, policy compliance, identity verification, and clear communication with users.

These examples reflect real-world security-related responsibilities in an IT support role and highlight my ability to recognize potential threats, follow established procedures, escalate appropriately, and maintain system and user security while minimizing disruption.

## Tickets Included
- Suspected phishing email
- Account locked after multiple failed login attempts
- Software installation request requiring administrative rights
- Antivirus threat detected
