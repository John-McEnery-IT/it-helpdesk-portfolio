TICKET TITLE:
Software Installation Request (Admin Rights Required)

CATEGORY:
Security / Software

PRIORITY:
Low

ENVIRONMENT:
Device: Desktop PC
Operating System: Windows 10
Account Type: Domain user account
Location: Office Environment


--------------------------------

USER ISSUE:
User requests the installation of third-party software but does not have the required administrative privileges to install applications.

---------------------------------

INITIAL CHECKS:
- Confirmed the name and purpose of the requested software.
- Verified the user did not have local administrative privileges.
- Asked whether the software was required for job duties.
- Confirmed the software was not already approved or installed.

--------------------------------

TROUBLESHOOTING STEPS:
1. Reviewed company policy regarding software installation.
2. Confirmed the software required administrative rights.
3. Informed the user that installation could not proceed without approval.
4. Submitted a software installation request for review by the IT team.
5. Advised the user on alternative approved software options, if available.

--------------------------------

RESOLUTION:
The request was escalated for approval in accordance with company security policy.


--------------------------------

OUTCOME:
User was informed of the approval process and next steps.

--------------------------------

TICKET STATUS:
Escalated
