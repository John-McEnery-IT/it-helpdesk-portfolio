# Qwiklabs – Software Management (Windows & Linux)

## Lab Overview
This lab focused on managing software applications in both Windows and Linux environments. The objective was to install, update, and remove applications using appropriate tools for each operating system.

## Tasks Performed
- Installed a web browser (Firefox)
- Updated an existing application (VLC)
- Uninstalled an application (GIMP)
- Verified application status after each change

## Operating Systems Used
- Windows
- Linux

## Tools Used
- Windows application management tools
- Linux package management tools

## What This Demonstrates
This lab demonstrates an understanding of the software lifecycle, including installation, updates, and removal. It also highlights the ability to perform similar tasks across different operating systems using appropriate system tools.

## Relevance to IT Support
Software installation, maintenance, and removal are daily responsibilities in IT support roles. This lab reflects real-world Tier 1 tasks and reinforces proper change handling, verification, and user impact awareness.
