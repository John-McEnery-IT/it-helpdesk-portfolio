
Module 5 – Software and Applications

Module 5 Summary
Module 5 focused on software and application support tasks commonly handled by Tier 1 IT support technicians. Topics included software installation, application updates, software removal, and troubleshooting application launch issues.

During this module, I documented realistic helpdesk tickets covering approved software installations, application updates, software uninstallation requests, and applications failing to launch. Each ticket demonstrates a structured troubleshooting approach, adherence to administrative permission boundaries, and proper verification of successful outcomes.

These examples reflect everyday software support responsibilities in an IT environment and highlight my ability to manage the software lifecycle, follow organizational policies, and resolve application-related issues efficiently while maintaining clear communication with users.

- Application update required
