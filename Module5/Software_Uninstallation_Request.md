TICKET TITLE:
Software Uninstallation Request


CATEGORY:
Software / Application Support

PRIORITY:
Low

ENVIRONMENT:
Device: Desktop PC
Operating System: Windows 10
Application: Graphics editing software
Account Type: Standard user
Location: Office environment


--------------------------------

USER ISSUE:
User requests the removal of an installed application that is no longer required for their role.

---------------------------------

INITIAL CHECKS:
- Confirmed the application was no longer required for job duties.
- Verified the software was not critical to other systems or workflows.
- Confirmed the user did not have administrative privileges.
- Checked that no active files or processes were using the application.

--------------------------------

TROUBLESHOOTING STEPS:
1. Accessed system application management tools.
2. Uninstalled the application using administrative credentials.
3. Verified the application was fully removed from the system.
4. Restarted the system to apply changes.
5. Confirmed the application no longer appeared in the installed programs list.

--------------------------------

RESOLUTION:
The requested application was successfully uninstalled from the system.

--------------------------------

OUTCOME:
User confirmed the application was removed and no longer accessible.

--------------------------------

TICKET STATUS:
Resolved
