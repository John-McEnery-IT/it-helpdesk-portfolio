TICKET TITLE:
Computer Running Slowly


CATEGORY:
Troubleshooting / Performance

PRIORITY:
Medium

ENVIRONMENT:
Device: Desktop PC
Operating System: Windows 10
Account Type: Standard user
Location: Office environment


--------------------------------

USER ISSUE:
User reports that their computer is running slowly, with applications taking longer than usual to open and respond.
---------------------------------

INITIAL CHECKS:
- Asked the user when the performance issue started.
- Confirmed whether the issue affected all applications or only specific ones.
- Verified whether any recent changes were made to the system.
- Confirmed the issue affected only this user.

--------------------------------

TROUBLESHOOTING STEPS:
1. Checked system resource usage (CPU, memory, disk) using Task Manager.
2. Identified high disk usage caused by low available disk space.
3. Ran Disk Cleanup to remove temporary files.
4. Deleted unnecessary files from the Downloads folder and cleared the Recycle Bin.
5. Checked startup programs and disabled non-essential items.
6. Restarted the system to apply changes.

--------------------------------

RESOLUTION:
The issue was resolved by freeing up disk space and reducing unnecessary startup processes, which improved overall system performance.

--------------------------------

OUTCOME:
User confirmed the system performance returned to normal and applications were responding as expected.
--------------------------------

TICKET STATUS:
Resolved
