TICKET TITLE:
Wi-Fi Connection Issue


CATEGORY:
Networking / Connectivity

PRIORITY:
Medium

ENVIRONMENT:
Device: Laptop
Operating System: Windows 10
Connection Type: Wireless
Location: Office environment


--------------------------------

USER ISSUE:
User reports they are unable to connect to the corporate Wi-Fi network and cannot access the internet.
---------------------------------

INITIAL CHECKS:
- Confirmed the user could see available Wi-Fi networks.
- Asked whether other devices could connect to the same network.
- Verified whether the issue affected only this user or multiple users.
- Checked if the user recently changed locations or devices.

--------------------------------

TROUBLESHOOTING STEPS:
1. Verified Wi-Fi was enabled on the device and airplane mode was disabled.
2. Confirmed the correct corporate network was selected.
3. Checked the user’s network credentials and re-entered the Wi-Fi password.
4. Restarted the laptop and network adapter.
5. Checked IP configuration to ensure the device received a valid IP address.
6. Tested connectivity by accessing internal and external websites.

--------------------------------

RESOLUTION:
The issue was resolved by reconnecting to the corporate Wi-Fi network and refreshing network credentials.

--------------------------------

OUTCOME:
User confirmed they were able to connect to Wi-Fi and access the internet successfully.
--------------------------------

TICKET STATUS:
Resolved
